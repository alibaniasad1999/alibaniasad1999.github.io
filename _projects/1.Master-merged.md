## Abstract

This project presents a zero-sum multi-agent reinforcement learning (MARL) framework for robust spacecraft guidance in the Earth–Moon three-body dynamical environment. The formulation treats guidance as a two-player differential game (guidance agent vs. disturbance agent) and demonstrates improved robustness and performance under many uncertainty scenarios.

**Key contributions:**
- Zero-sum differential-game formulation for low-thrust guidance
- Zero-sum multi-agent extensions of DDPG, TD3, SAC, and PPO
- Comprehensive robustness evaluation (sensor noise, actuator disturbance, time delay, model mismatch)
- ROS2 + C++ real-time inference for deployment

## Highlights

- Robustness: MA-TD3 reduces trajectory error and improves success rate under combined uncertainty.
- Practical: C++ inference runs <5 ms; ROS2 integration included for hardware-in-the-loop.
- Reproducible: notebooks and scripts included for training and robustness evaluation.

## Algorithms implemented

- MA-DDPG — Differential-game DDPG with two-player actor/critic pairs
- MA-TD3 — Twin critics, policy smoothing and clipped double Q-learning in a zero-sum setup
- MA-SAC — Entropy-regularised zero-sum actor–critic
- MA-PPO — On-policy zero-sum PPO with clipped surrogate objective

See the full algorithmic descriptions and pseudo-code in the thesis repository.

## Repository & How to run

Clone the repo and follow the instructions in `README.md`:

```bash
git clone https://github.com/alibaniasad1999/master-thesis.git
cd master-thesis
# create venv and install
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Key directories:
- `Report/` — LaTeX thesis and plots
- `Code/Python/` — RL implementations and notebooks
- `Code/C/` — C++ inference
- `Code/ROS2/` — ROS2 packages for deployment

## Key results (summary)

- MA-TD3: best overall (trajectory error, fuel efficiency, success rate)
- MA-SAC: strong stability and entropy-driven exploration
- All zero-sum variants show tighter performance distributions under uncertainty
